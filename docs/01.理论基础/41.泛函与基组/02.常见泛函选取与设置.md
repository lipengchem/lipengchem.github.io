# 计算中常见交换-相关泛函的选取与设置指南

密度泛函理论（Density Functional Theory, DFT）是当前材料模拟和分子模拟中最广泛使用的计算方法之一。而交换-相关能泛函（Exchange-Correlation Functional, XC Functional）的选择，则直接决定了计算的精度、适用性以及物理可靠性，因此本文章整理了常用 XC 泛函的理论基础、适用范围以及如何在主流程序中设置。

<!-- more -->

## 什么是交换-相关泛函？



在 DFT 中，系统的总能量写作：
$$E[\rho] = T_s[\rho] + V_{\text{ext}}[\rho] + J[\rho] + E_{\text{xc}}[\rho]$$

其中：

- $T_s[\rho]$：非交换系统的动能；
- $V_{\text{ext}}[\rho]$：电子在外部势能中的能量（如原子核的库仑吸引）；
- $J[\rho]$：经典电子之间的库仑排斥能（又称 Hartree 能）；
- $E_{\text{xc}}[\rho]$：交换-关联能量，包含电子交换对称性和量子多体效应。

由于 $E_{\text{xc}}[\rho]$ 的精确表达式无法精确解析，因此在实际计算中必须通过各种近似方法来估算。





## Jacob's Ladder：从近似到“天堂”的五阶泛函

| 等级 | 泛函类型         | 示例                     | 精度 ↑ | 计算量 ↑ |
|------|------------------|--------------------------|--------|----------|
| 1    | LDA              | VWN, CA                  | ★      | ★        |
| 2    | GGA              | PBE, RPBE, BLYP          | ★★     | ★★       |
| 3    | meta-GGA         | SCAN, TPSS, M06-L        | ★★★    | ★★★      |
| 4    | 杂化泛函 Hybrid  | B3LYP, HSE06, PBE0       | ★★★★   | ★★★★     |
| 5    | RPA / Double-Hybrid | RPA@PBE, B2PLYP       | ★★★★★  | ★★★★★    |


## 各类常用泛函详解

### 🔹 LDA（Local Density Approximation）

- 只依赖密度本身，基于均匀电子气模型；
- 快速、计算量小，但通常低估晶格常数和能隙；
- 适合金属体系或大体积测试。

**代表**：VWN、CA（Ceperley–Alder）


### 🔹 GGA（Generalized Gradient Approximation）

- 引入密度梯度修正，改善结构与能量描述；
- PBE 是最常用的默认泛函；
- RPBE 修正吸附过强的问题；
- BLYP 常用于有机分子模拟。

**适用**：结构优化、表面吸附、稳定性分析等


### 🔹 meta-GGA（如 SCAN）

- 加入动能密度项，能更好描述非局域效应；
- SCAN 是无经验型泛函，适用范围广；
- M06-L 对分子反应更有效，TPSS 是过渡型函数。

**优点**：在不显著增加计算成本的前提下接近杂化泛函精度。


### 🔹 杂化泛函（Hybrid Functionals）

- 将一部分 HF（Hartree-Fock）交换与 GGA 结合，提高电子结构精度；
- HSE06 局域化 HF 交换，适合固体材料；
- B3LYP 为经典分子化学泛函，广泛用于小分子；
- PBE0 为全局混合泛函，适用于中等体系。

**适用**：带隙计算、缺陷能、光学性质、电荷分布、反应路径分析等。


### 🔹 RPA 与 Double-Hybrid 泛函

- 描述电子关联更准确，理论极限；
- 用于小体系的能量排序、基准研究；
- 计算资源极大，不适合大体系。


## 各程序中的设置方式

### ✅ VASP


| 泛函        | 设置示例                                                                 |
|-------------|--------------------------------------------------------------------------|
| PBE         | `GGA = PE`（默认）                                                      |
| RPBE        | `GGA = RP`                                                              |
| PBEsol      | `GGA = PS`                                                              |
| SCAN        | `METAGGA = SCAN` + `LASPH = .TRUE.`                                     |
| HSE06       | `LHFCALC = .TRUE.`，`HFSCREEN = 0.2`，`AEXX = 0.25`                      |
| PBE+U       | `LDAU = .TRUE.`，配合 `LDAUL`, `LDAUU`, `LDAUJ`                          |
| B3LYP（近似） | `GGA = B3`, `AEXX = 0.20`, `AGGAX = 0.72`, `AGGAC = 0.81`, `ALDAC = 0.19` |

> 💡 注：
> - VASP 不原生支持 B3LYP；
> - 上述设置为手动近似模拟其交换-相关结构（不能等效于 Gaussian 中的 B3LYP）；
> - 建议如需准确使用 B3LYP，请选用支持该函数的程序如 Gaussian、ORCA、Q-Chem 等；
> - 固体体系推荐优先使用 HSE06 / PBE0。




### ✅ Gaussian

| 泛函      | 使用方式（头文件）                      |
|-----------|------------------------------------------|
| B3LYP     | `# B3LYP/6-31G(d)`                       |
| M06-2X    | `# M06-2X/def2TZVP`                      |
| CAM-B3LYP | `# CAM-B3LYP/6-311++G**`                 |
| ωB97XD    | 含长程修正 + 色散                        |
| DFT-D3    | 加入 `EmpiricalDispersion=GD3`           |


### ✅ ORCA

- 设置泛函：`! B3LYP def2-TZVP TightSCF`
- 加入色散修正：`%method Dispersion D3BJ end`
- 支持 HSE06、PBE0、B97-3c 等多种混合泛函


### ✅ CP2K

- 基于 `&XC_FUNCTIONAL` 块设置，如：

```txt
&XC_FUNCTIONAL
  &PBE
  &END
&END XC_FUNCTIONAL
```
- 使用 &HF 添加杂化交换；支持 RI 和 ADMM 加速。


### ✅ Quantum ESPRESSO

- 在输入卡中添加如下内容：

```txt
input_dft = 'PBE', 'RPBE', 'BLYP', 'HSE', etc.
exx_fraction = 0.25        ! For hybrid functionals like HSE06
screening_parameter = 0.2  ! Only relevant for screened hybrids (e.g., HSE06)
```

在命令行环境中，高效使用文本编辑器是科研、开发与系统管理的基本技能之一。本文将简要介绍常用编辑器（如 Vim、Nano、Emacs）的基本用法。

<!-- more -->

### Vim的使用
在命令行环境中，`vim` 是一款功能强大且广泛使用的文本编辑器。相比于 `nano` 的简单易用，`vim` 更强调效率与可扩展性，是许多程序员和科研工作者的首选。

#### 1. **Vim 的三种模式**

| 模式名称     | 功能                     | 进入方式                     |
|--------------|--------------------------|------------------------------|
| 正常模式     | 默认模式，执行命令       | 打开文件即为此模式，或按 `Esc` |
| 插入模式     | 编辑文本内容             | `i`, `a`, `o` 等命令进入     |
| 命令模式     | 保存、退出、查找等操作   | 正常模式下输入 `:`           |
#### 2. **常用命令总览**

- 启动与退出
```bash
vi filename          # 打开文件
:q                   # 退出（未修改时）
:q!                  # 强制退出（不保存）
:w                   # 保存
:wq 或 :x            # 保存并退出
ZZ                   # 保存并退出（快捷）
```
- 插入文本
```bash
i   # 在光标前插入
a   # 在光标后插入
o   # 在下方新起一行并插入
O   # 在上方新起一行并插入
```

- 删除/复制/粘贴
```bash
x        # 删除光标处字符
dd       # 删除整行
yy       # 复制整行
p        # 粘贴至下一行
u        # 撤销操作
Ctrl + r # 恢复撤销
:30,40d      #删除第 30 到 40 行
:30,$d       #删除第 30 行到文件末尾
:1,10d       #删除第 1 到 10 行
:%d          #删除全文
```
- 翻页与跳转命令
```bash
h/j/k/l      # 左/下/上/右
0 / $        # 行首 / 行尾
Ctrl + f     # 向下翻一页（forward）
Ctrl + b     # 向上翻一页（backward）
Ctrl + d     # 向下翻半页（down）
Ctrl + u     # 向上翻半页（up）
gg           # 跳转到第一行
G            # 跳转到最后一行
50G          # 跳转到第 50 行
:n           # 跳转到第 n 行
```

- 查找与替换
```bash
/pattern     # 向下查找
?pattern     # 向上查找
n / N        # 重复上一次查找（正/反方向）
:%s/旧/新/g  # 全文替换
:%s/旧/新/gc # 全文替换并逐个确认
```

在第一性原理计算中，结构优化得到的反应能 $\Delta E$ 本质上是静态电子能量差。对于含氢键、羟基或质子转移的反应，轻元素振动带来的零点能和有限温度熵效应往往不可忽略。因此，在讨论反应热力学或动力学能垒时，通常需要把静态能量 $\Delta E$ 转换为有限温度下的自由能变化 $\Delta G$。

<!-- more -->

## 1. $\Delta E$ 和 $\Delta G$ 的区别

VASP 结构优化结束后，常从 `OUTCAR` 中提取总能量，用于计算反应能、吸附能或能垒。例如：

$$\Delta E = E_{\mathrm{FS}} - E_{\mathrm{IS}}$$

其中 $\mathrm{IS}$ 表示初态，$\mathrm{FS}$ 表示终态。如果研究过渡态，则静态能垒写作：

$$\Delta E^{\ddagger} = E_{\mathrm{TS}} - E_{\mathrm{IS}}$$

这里的 $E$ 主要来自电子结构计算，可以理解为给定原子构型下的势能面能量。它并不包含完整的热力学贡献，例如原子振动、分子平动、转动以及熵项。实验中讨论的反应趋势或能垒通常发生在有限温度下，因此更严格的量是自由能：

$$G(T) = E_{\mathrm{DFT}} + G_{\mathrm{corr}}(T)$$

自由能校正的目标，就是计算每个构型的 $G_{\mathrm{corr}}(T)$，再用校正后的 $G$ 计算反应自由能：

$$\Delta G = G_{\mathrm{FS}} - G_{\mathrm{IS}}$$

或自由能垒：

$$\Delta G^{\ddagger} = G_{\mathrm{TS}} - G_{\mathrm{IS}}$$

需要注意，VASP `OUTCAR` 中的 `free energy TOTEN` 主要与电子自洽和展宽有关，并不是这里讨论的热力学 Gibbs 自由能。做反应能比较时，应该在所有构型中使用同一种能量定义，并在此基础上再加入振动和熵校正。

## 2. 自由能校正的热力学来源

对一个构型 $i$，常用表达式为：

$$G_i(T) = E_{i,\mathrm{DFT}} + E_{i,\mathrm{ZPE}} + \Delta H_i(T) - T S_i(T)$$

其中：

| 符号 | 含义 | 说明 |
| --- | --- | --- |
| $E_{\mathrm{DFT}}$ | 静态 DFT 总能量 | 来自结构优化后的单点或优化能量 |
| $E_{\mathrm{ZPE}}$ | 零点振动能 | 量子振动在 0 K 下仍然存在 |
| $\Delta H(T)$ | 有限温度热焓校正 | 由振动、平动、转动等热运动贡献 |
| $S(T)$ | 熵 | 气相分子的熵通常较大，吸附物熵通常较小 |
| $G_{\mathrm{corr}}$ | 总自由能校正 | $E_{\mathrm{ZPE}} + \Delta H - TS$ |

在差分形式下：

$$\Delta G = \Delta E_{\mathrm{DFT}} + \Delta E_{\mathrm{ZPE}} + \Delta H - T\Delta S$$

对于表面吸附态或固体内部质子迁移，平动和转动自由度被表面或晶格限制，常采用谐振子近似，只考虑振动自由能：

$$G_{\mathrm{ads}}(T) \approx E_{\mathrm{DFT}} + E_{\mathrm{ZPE,vib}} + \Delta H_{\mathrm{vib}}(T) - T S_{\mathrm{vib}}(T)$$

对于气相分子，例如 $\mathrm{H_2}$、$\mathrm{H_2O}$、$\mathrm{OH\cdot}$，则需要考虑平动、转动和振动贡献：

$$G_{\mathrm{gas}}(T,p) = E_{\mathrm{DFT}} + E_{\mathrm{ZPE}} + \Delta H_{\mathrm{trans/rot/vib}}(T) - T S_{\mathrm{trans/rot/vib}}(T,p)$$

因此，吸附物和气相分子的自由能校正不能混用。

## 3. 为什么质子转移体系特别需要校正

质子转移反应通常包含 O-H、H-bond 或 H-transfer 振动模式。由于 H 原子质量很小，相关振动频率较高，零点能贡献明显。也就是说，即使两个构型的静态能量差 $\Delta E$ 看起来不大，加入 $\Delta E_{\mathrm{ZPE}}$ 后也可能改变反应能或能垒的数值。

例如羟基相关的质子转移可以抽象为：

- $\mathrm{IS}$：$\mathrm{O-H\cdots X}$
- $\mathrm{FS}$：$\mathrm{O\cdots H-X}$
- $\mathrm{TS}$：$\mathrm{O\cdots H\cdots X}$

此时应分别计算 $\mathrm{IS}$、$\mathrm{FS}$ 和 $\mathrm{TS}$ 的自由能校正：

$$\Delta G = \left(E_{\mathrm{FS}} + G_{\mathrm{corr,FS}}\right) - \left(E_{\mathrm{IS}} + G_{\mathrm{corr,IS}}\right)$$

$$\Delta G^{\ddagger} = \left(E_{\mathrm{TS}} + G_{\mathrm{corr,TS}}\right) - \left(E_{\mathrm{IS}} + G_{\mathrm{corr,IS}}\right)$$

如果体系总组成相同，并且初态、终态和过渡态都在相同 slab 或相同团簇模型中，表面或骨架部分的很多贡献会在差分中部分抵消。但与 H 迁移相关的局域振动仍然需要认真处理。

## 4. 总体计算流程

建议按照以下流程进行：

```txt
明确反应式
  ↓
优化 IS、FS、TS 结构
  ↓
高精度静态计算，提取 E_DFT
  ↓
对每个构型做频率计算
  ↓
检查虚频和振动模式
  ↓
提取 ZPE、H、S 或 Gcorr
  ↓
计算 ΔG 和 ΔG‡
```

其中：

- $\mathrm{IS}$ 和 $\mathrm{FS}$ 应为稳定构型，一般不应有明显虚频。
- $\mathrm{TS}$ 应有且只有一个主要虚频。
- $\mathrm{TS}$ 的虚频模式应对应质子从供体到受体的迁移方向。

为了避免文件混乱，建议每个构型单独建一个目录。例如：

```bash
mkdir -p IS FS TS
```

每个构型目录内部再按计算任务分成：

```txt
IS/
├── opt/       # 结构优化
├── static/    # 高精度静态单点，提取 E_DFT
└── freq/      # 频率计算，提取 Gcorr
```

`FS` 和 `TS` 目录同理。后续所有构型都按相同方式处理，最后再把 `IS/static`、`FS/static`、`TS/static` 的能量和 `IS/freq`、`FS/freq`、`TS/freq` 的热力学校正汇总到一个表格里。

下面的命令默认从反应项目根目录执行，也就是能直接看到 `IS`、`FS`、`TS` 三个文件夹的位置。

## 5. 第一步：结构优化

自由能校正建立在可靠结构的基础上。初态、终态和过渡态必须使用一致的计算设置，否则能量差不可比。

以初态 `IS` 为例，先进入结构优化目录：

```bash
mkdir -p IS/opt
cd IS/opt
```

准备优化所需文件：

```bash
cp /path/to/POSCAR ./POSCAR
cp /path/to/POTCAR ./POTCAR
cp /path/to/KPOINTS ./KPOINTS
cp /path/to/INCAR ./INCAR
cp /path/to/vasp.script ./vasp.script
```

其中 `/path/to/` 替换为自己的模板文件路径。如果已经在当前目录准备好了这些文件，也可以直接提交优化任务。

结构优化这一步的 `INCAR` 重点是让原子充分弛豫。对于表面吸附或质子转移体系，可以先确认以下参数：

```txt
SYSTEM = IS optimization

ISTART = 0
ICHARG = 2

ENCUT  = 500
PREC   = Accurate
EDIFF  = 1E-5
EDIFFG = -0.02
LREAL  = Auto
ADDGRID = .TRUE.
LASPH  = .TRUE.

IBRION = 2
NSW    = 200
ISIF   = 2
POTIM  = 0.2

ISPIN  = 2
MAGMOM = ...

LWAVE  = .FALSE.
LCHARG = .FALSE.
```

如果是从普通结构优化模板改来，主要检查这些项目：

| 项目 | 优化计算中的设置 | 目的 |
| --- | --- | --- |
| `IBRION = 2` | 共轭梯度离子优化 | 优化原子位置 |
| `NSW = 200` | 允许足够多离子步 | 避免结构未收敛就停止 |
| `EDIFFG = -0.02` | 力收敛标准，可按需要改为 `-0.03` 或 `-0.01` | 控制优化精度 |
| `ISIF = 2` | 优化离子位置，不改变晶胞 | 常用于 slab 或固定晶胞模型 |
| `ISPIN = 2` 和 `MAGMOM` | 含自由基或磁性体系需要设置 | 描述未成对电子 |

需要保持一致的项目包括：

- 赝势版本和元素顺序：`POTCAR`
- 截断能：`ENCUT`
- k 点采样：`KPOINTS`
- 交换相关泛函，例如 PBE
- 色散校正，例如 D3/D4
- slab 厚度、真空层和固定原子方式
- 自旋设置
- 溶剂模型设置，如果使用隐式溶剂

对于羟基自由基或含未成对电子的体系，通常需要开启自旋极化：

```txt
ISPIN = 2
```

并根据体系设置合理的初始磁矩：

```txt
MAGMOM = ...
```

优化完成后，建议检查：

- 结构是否化学合理；
- 关键键长是否正常；
- 质子是否仍位于预期位置；
- 磁矩是否符合自由基或磁性体系的物理图像。

优化结束后，确认 `CONTCAR` 存在并且结构合理：

```bash
ls CONTCAR OUTCAR OSZICAR
grep "reached required accuracy" OUTCAR
tail -n 20 OSZICAR
```

如果是 `FS` 或 `TS`，重复相同流程：

```bash
mkdir -p ../../FS/opt
mkdir -p ../../TS/opt
```

然后分别放入对应的 `POSCAR`，保持 `POTCAR`、`KPOINTS`、`INCAR` 和提交脚本的设置一致。

## 6. 第二步：高精度静态计算

结构优化的主要目的是得到稳定构型，而最终用于能量比较的 $E_{\mathrm{DFT}}$，更推荐从优化结构上的高精度静态单点计算中提取。这样可以避免离子步优化过程中的数值设置、收敛精度或最后一步力收敛细节对能量比较产生影响。

常见做法是新建一个 `static` 文件夹：

```bash
mkdir -p IS/static
cp IS/opt/CONTCAR IS/static/POSCAR
cp IS/opt/POTCAR IS/opt/KPOINTS IS/opt/vasp.script IS/static/
cp IS/opt/INCAR IS/static/INCAR
cd IS/static
```

然后修改 `static/INCAR`。静态计算不再移动原子，因此关键参数是：

```txt
SYSTEM = Static single point

ISTART = 0
ICHARG = 2

ENCUT  = 500
PREC   = Accurate
EDIFF  = 1E-7
LREAL  = .FALSE.
ADDGRID = .TRUE.
LASPH  = .TRUE.

IBRION = -1
NSW    = 0

ISPIN  = 2
LORBIT = 11

LWAVE  = .FALSE.
LCHARG = .FALSE.
```

相对于 `opt/INCAR`，静态计算主要修改以下几项：

| 参数 | 从优化计算改为 | 原因 |
| --- | --- | --- |
| `SYSTEM` | `Static single point` | 标记当前任务，避免后期混淆 |
| `EDIFF` | 例如从 `1E-5` 改为 `1E-7` | 提高电子能量收敛精度 |
| `IBRION` | 从 `2` 改为 `-1` | 关闭离子步优化 |
| `NSW` | 从 `200` 改为 `0` | 只做单点计算 |
| `LREAL` | 从 `Auto` 改为 `.FALSE.` | 提高能量和力的数值精度 |
| `LORBIT` | 设置为 `11` | 在 `OUTCAR` 中输出分原子、分轨道的局域磁矩 |
| `LWAVE`、`LCHARG` | 通常设为 `.FALSE.` | 不保存不必要的大文件 |

如果希望利用优化计算的波函数或电荷密度加速收敛，也可以额外复制 `WAVECAR` 或 `CHGCAR`，并把 `ISTART`、`ICHARG` 改成续算形式：

```bash
cp IS/opt/WAVECAR IS/static/
cp IS/opt/CHGCAR IS/static/
```

```txt
ISTART = 1
ICHARG = 1
```

如果不确定前一步文件是否可靠，保持 `ISTART = 0`、`ICHARG = 2` 重新自洽更稳妥，只是耗时会更长。

其中：

| 参数 | 作用 |
| --- | --- |
| `IBRION = -1` | 不进行离子步优化 |
| `NSW = 0` | 静态单点计算 |
| `EDIFF = 1E-7` | 提高电子步收敛精度 |
| `LREAL = .FALSE.` | 提高力和能量精度 |
| `LASPH = .TRUE.` | 对含过渡金属、表面或吸附体系通常更稳妥 |

如果体系较小，或能量差很敏感，可以在静态计算中适当加密 `KPOINTS`。但必须注意：`IS`、`FS` 和 `TS` 的静态计算设置必须完全一致，否则 $\Delta E$ 不可比。

静态计算完成后，从 `OUTCAR` 或 `OSZICAR` 中提取总能量，作为后续表格中的 $E_{\mathrm{DFT}}$。频率计算的作用则是提供 $G_{\mathrm{corr}}$，不要把频率计算目录里的能量和静态计算目录里的能量混着比较。

提交静态计算：

```bash
sbatch vasp.script
```

计算结束后提取能量：

```bash
grep "free  energy   TOTEN" OUTCAR | tail -n 1
grep "energy  without entropy" OUTCAR | tail -n 1
tail -n 5 OSZICAR
```

如果体系中含有羟基自由基，静态计算后还应检查未成对电子是否仍主要局域在 $\mathrm{OH}$ 附近。只看普通电荷密度不能直接证明自由基特征，更直接的做法是看 `OUTCAR` 中的局域磁矩：

```bash
grep -A80 "magnetization (x)" OUTCAR
```

其中 `-A80` 表示从匹配到 `magnetization (x)` 这一行开始，继续显示后面 80 行。输出表格中的 `# of ion` 对应 `POSCAR` 中的原子编号，`tot` 列是该原子的总局域磁矩。判断 $\mathrm{OH}$ 是否仍具有自由基特征时，应找到羟基中 O 和 H 的原子编号，重点看它们对应行的 `tot` 数值是否有明显磁矩。

如果还希望用 VESTA 或其他可视化软件查看自旋密度分布，可以在静态计算中把电荷密度输出打开：

```txt
LCHARG = .TRUE.
```

对于 `ISPIN = 2` 的计算，`CHGCAR` 中可包含自旋相关信息，后续可以进一步作自旋密度图。简单判断局域磁矩时，优先看 `OUTCAR` 的 `magnetization (x)` 表；需要看空间分布图时，再输出 `CHGCAR`。

对 `FS` 和 `TS` 也做同样操作。推荐最终记录：

```txt
IS/static/OUTCAR  -> E_DFT(IS)
FS/static/OUTCAR  -> E_DFT(FS)
TS/static/OUTCAR  -> E_DFT(TS)
```

## 7. 第三步：频率计算

频率计算建议单独放在 `freq` 文件夹中。仍以 `IS` 为例，从优化目录复制结构和必要文件：

```bash
mkdir -p IS/freq
cp IS/opt/CONTCAR IS/freq/POSCAR
cp IS/opt/POTCAR IS/opt/KPOINTS IS/opt/vasp.script IS/freq/
cp IS/opt/INCAR IS/freq/INCAR
cd IS/freq
```

常用 `INCAR` 设置如下：

```txt
SYSTEM = Frequency calculation

ISTART = 0
ICHARG = 2

ENCUT  = 500
PREC   = Accurate
EDIFF  = 1E-7
LREAL  = .FALSE.
ADDGRID = .TRUE.

IBRION = 5
POTIM  = 0.02
NFREE  = 2
NSW    = 1
ISYM   = 0

ISPIN  = 2

LWAVE  = .FALSE.
LCHARG = .FALSE.
```

相对于 `opt/INCAR`，频率计算主要修改以下几项：

| 参数 | 从优化计算改为 | 原因 |
| --- | --- | --- |
| `SYSTEM` | `Frequency calculation` | 标记当前任务 |
| `EDIFF` | 例如从 `1E-5` 改为 `1E-7` | 频率来自力常数，电子步要更严格 |
| `IBRION` | 从 `2` 改为 `5` | 用有限差分计算振动频率 |
| `NSW` | 从 `200` 改为 `1` | 只触发频率计算，不继续优化 |
| `POTIM` | 改为 `0.01-0.03`，常用 `0.02` | 设置有限差分位移步长 |
| `NFREE` | 设置为 `2` | 使用中心差分 |
| `ISYM` | 设置为 `0` | 关闭对称性，避免约束振动模式 |
| `LREAL` | 改为 `.FALSE.` | 提高力的精度 |

注意，频率计算的结构必须来自已经收敛的 `CONTCAR`，不要继续使用优化前的 `POSCAR`。如果 `IS`、`FS`、`TS` 都要做频率，文件准备可以写成：

```bash
mkdir -p FS/freq TS/freq

cp FS/opt/CONTCAR FS/freq/POSCAR
cp FS/opt/POTCAR FS/opt/KPOINTS FS/opt/vasp.script FS/freq/
cp FS/opt/INCAR FS/freq/INCAR

cp TS/opt/CONTCAR TS/freq/POSCAR
cp TS/opt/POTCAR TS/opt/KPOINTS TS/opt/vasp.script TS/freq/
cp TS/opt/INCAR TS/freq/INCAR
```

随后分别进入 `FS/freq` 和 `TS/freq`，按同样方式修改各自的 `INCAR`。

主要参数含义：

| 参数 | 作用 |
| --- | --- |
| `IBRION = 5` | 使用有限差分计算 Hessian 矩阵 |
| `POTIM = 0.02` | 原子位移步长，常用 0.01-0.03 Å |
| `NFREE = 2` | 中心差分，一般比单边差分稳定 |
| `NSW = 1` | 只做频率计算，不继续结构优化 |
| `ISYM = 0` | 关闭对称性，避免振动模式被错误约束 |
| `EDIFF = 1E-7` | 提高电子收敛精度，使力常数更稳定 |
| `LREAL = .FALSE.` | 提高力的精度，适合频率计算 |

对于大 slab 体系，不一定要对所有原子做频率。更常见的做法是只放开反应中心附近的原子，例如：

- 转移的 H；
- 羟基 O；
- 质子受体原子；
- 与反应中心直接相连的表面原子；
- 可能参与氢键重排的近邻原子。

远离反应中心的 slab 原子可以固定，以降低计算量并减少低频表面振动带来的数值噪声。

如果只想对反应中心附近原子做频率，需要在 `freq/POSCAR` 中保留 `Selective Dynamics`，将参与频率计算的原子设为 `T T T`，其余固定为 `F F F`。例如：

```txt
Selective Dynamics
Cartesian
...
O_x  O_y  O_z  T T T
H_x  H_y  H_z  T T T
X_x  X_y  X_z  T T T
...
slab_atom_x slab_atom_y slab_atom_z F F F
```

提交频率计算：

```bash
sbatch vasp.script
```

`FS/freq` 和 `TS/freq` 也按同样方式建立和提交。注意：频率计算的 `POSCAR` 必须来自对应构型自己的优化结果，不要把 `IS` 的 `CONTCAR` 误复制到 `FS/freq` 或 `TS/freq`。

## 8. 第四步：检查虚频

频率计算结束后，可用：

```bash
cd IS/freq
grep "cm-1" OUTCAR
```

或：

```bash
grep "f/i" OUTCAR
```

判断原则：

| 构型 | 期望频率特征 |
| --- | --- |
| $\mathrm{IS}$ | 无明显虚频 |
| $\mathrm{FS}$ | 无明显虚频 |
| $\mathrm{TS}$ | 一个主要虚频 |

VASP 输出中，虚频通常以 `f/i=` 标记，实频通常以 `f  =` 标记。对于质子转移过渡态，唯一虚频的振动方向应当对应 H 在供体和受体之间移动。如果虚频方向不是反应坐标，则说明过渡态结构可能不正确。

小虚频需要谨慎判断。对于表面体系，几十 `cm-1` 的低频虚频有时来自 slab 低频摆动或数值误差；但如果虚频很大，或者对应关键化学键变化，就不能简单忽略。

对三个构型都检查一遍：

```bash
grep "f/i" IS/freq/OUTCAR
grep "f/i" FS/freq/OUTCAR
grep "f/i" TS/freq/OUTCAR
```

如果 `TS` 有一个虚频，还需要用可视化软件或振动模式文件确认该虚频确实对应质子转移方向。

## 9. 第五步：提取热力学校正

频率计算完成后，可以使用 VASPKIT 提取热力学校正。

### 9.1 吸附物或表面反应

对于表面吸附态，例如 $\mathrm{OH^\ast}$、$\mathrm{H^\ast}$、$\mathrm{O-H\cdots X^\ast}$，常用：

```txt
cd IS/freq
vaspkit
5
501
```

随后输入温度，例如：

```txt
298.15
```

该步骤通常用于得到吸附物在谐振子近似下的振动热力学校正。

对 `FS/freq` 和 `TS/freq` 重复同样操作：

```bash
cd ../../FS/freq
vaspkit
```

```bash
cd ../../TS/freq
vaspkit
```

### 9.2 气相分子

对于自由分子，例如 $\mathrm{H_2}$、$\mathrm{H_2O}$、$\mathrm{OH\cdot}$，常用：

```txt
cd gas_OH/freq
vaspkit
5
502
```

气相分子需要考虑平动、转动和振动贡献，因此不能直接使用吸附物的处理方式。

### 9.3 需要记录的量

建议为每个构型记录：

- $E_{\mathrm{DFT}}$：静态 DFT 总能量；
- $G_{\mathrm{corr}}$：频率计算得到的总自由能校正；
- $G = E_{\mathrm{DFT}} + G_{\mathrm{corr}}$：校正后的自由能。

如果使用 VASPKIT 的 `501` 处理吸附物振动热力学校正，通常直接记录输出中的 `Thermal correction to G(T)` 这一行即可。例如输出为：

```txt
Thermal correction to G(T) : 19.317 kcal/mol   0.837672 eV
```

则该构型在对应温度下的自由能校正为：

$$G_{\mathrm{corr}} = 0.837672\ \mathrm{eV}$$

`Zero-point energy E_ZPE`、`Thermal correction to H(T)` 和 `Entropy contribution T*S` 可以作为检查项保存，但不需要全部放进最终主表中。不要在使用 `Thermal correction to G(T)` 后再额外把 ZPE 或熵项重复加一遍。

可以建立一个汇总文件：

```bash
cd ../../
touch free_energy_summary.txt
```

然后把每个目录中得到的关键结果手动记录进去：

```txt
IS  E_DFT = ...  Gcorr = ...  G = ...
FS  E_DFT = ...  Gcorr = ...  G = ...
TS  E_DFT = ...  Gcorr = ...  G = ...
```

## 10. 第六步：计算 $\Delta G$

整理成表格最清楚：

| 构型 | $E_{\mathrm{DFT}}$ / eV | $G_{\mathrm{corr}}$ / eV | $G = E_{\mathrm{DFT}} + G_{\mathrm{corr}}$ / eV | 备注 |
| --- | ---: | ---: | ---: | --- |
| $\mathrm{IS}$ |  |  |  | 无明显虚频 |
| $\mathrm{FS}$ |  |  |  | 无明显虚频 |
| $\mathrm{TS}$ |  |  |  | 一个主要虚频 |

其中 $E_{\mathrm{DFT}}$ 来自 `static/OUTCAR`，$G_{\mathrm{corr}}$ 来自 `freq/OUTCAR` 经过 VASPKIT 提取的 `Thermal correction to G(T)`。所有构型必须使用同一温度，例如都用 `298.15 K` 或都用 `373 K`。

反应自由能：

$$\Delta G = G_{\mathrm{FS}} - G_{\mathrm{IS}}$$

自由能垒：

$$\Delta G^{\ddagger} = G_{\mathrm{TS}} - G_{\mathrm{IS}}$$

如果已经有静态能量差，也可以写成：

$$\Delta G = \Delta E + \left(G_{\mathrm{corr,FS}} - G_{\mathrm{corr,IS}}\right)$$

$$\Delta G^{\ddagger} = \Delta E^{\ddagger} + \left(G_{\mathrm{corr,TS}} - G_{\mathrm{corr,IS}}\right)$$

这种写法最适合展示“自由能校正到底改变了多少”。

## 11. 示例：从 $\Delta E$ 到 $\Delta G$

假设某质子转移反应的静态能量差为：

$$\Delta E = E_{\mathrm{FS}} - E_{\mathrm{IS}} = -0.20\ \mathrm{eV}$$

频率计算得到：

$$G_{\mathrm{corr,IS}} = 0.35\ \mathrm{eV}$$

$$G_{\mathrm{corr,FS}} = 0.42\ \mathrm{eV}$$

则：

$$\Delta G = \Delta E + \left(G_{\mathrm{corr,FS}} - G_{\mathrm{corr,IS}}\right) = -0.20 + (0.42 - 0.35) = -0.13\ \mathrm{eV}$$

加入自由能校正后，反应仍然放热/自发趋势更强的一侧仍是终态，但自由能差从 $-0.20\ \mathrm{eV}$ 变为 $-0.13\ \mathrm{eV}$，说明热力学校正削弱了终态稳定性。

如果过渡态静态能垒为：

$$\Delta E^{\ddagger} = E_{\mathrm{TS}} - E_{\mathrm{IS}} = 0.60\ \mathrm{eV}$$

并且：

$$G_{\mathrm{corr,TS}} = 0.39\ \mathrm{eV}$$

$$G_{\mathrm{corr,IS}} = 0.35\ \mathrm{eV}$$

则：

$$\Delta G^{\ddagger} = \Delta E^{\ddagger} + \left(G_{\mathrm{corr,TS}} - G_{\mathrm{corr,IS}}\right) = 0.60 + (0.39 - 0.35) = 0.64\ \mathrm{eV}$$

这就是校正后的质子转移自由能垒。

## 12. 涉及质子和电子时的额外校正

如果研究的是单个体系内部的质子迁移，例如：

$$\mathrm{O-H\cdots X} \rightarrow \mathrm{O\cdots H-X}$$

通常比较 $\mathrm{IS}$、$\mathrm{FS}$ 和 $\mathrm{TS}$ 的自由能即可。

但如果反应式中显式包含溶液中的质子和电子，例如电催化反应：

$$\mathrm{^\ast OH} + \mathrm{H^+} + e^- \rightarrow \mathrm{^\ast} + \mathrm{H_2O}$$

则需要进一步引入计算氢电极模型：

$$G(\mathrm{H^+} + e^-) = \frac{1}{2}G(\mathrm{H_2}) - eU - k_{\mathrm{B}}T\ln(10)\times \mathrm{pH}$$

在 298.15 K 下：

$$k_{\mathrm{B}}T\ln(10) \approx 0.05916\ \mathrm{eV}$$

因此 pH 校正通常写为：

$$\Delta G_{\mathrm{pH}} = 0.05916 \times \mathrm{pH}$$

如果体系还涉及电极电势、显式溶剂、隐式溶剂或外加电场，自由能还可能包含：

$$\Delta G = \Delta E + \Delta E_{\mathrm{ZPE}} - T\Delta S + \Delta G_{\mathrm{solv}} + \Delta G_{\mathrm{pH}} + \Delta G_U$$

这些项是否需要加入，取决于反应模型和研究问题。

## 13. 常见问题

### 13.1 能不能只对 H 做频率计算

不建议。H 的振动与供体原子、受体原子和局部环境强耦合。至少应包含 H、羟基 O、受体原子以及附近直接参与反应的原子。

### 13.2 为什么吸附物熵不能直接按气相分子处理

吸附物被固定在表面上，平动和转动自由度被显著限制。如果仍按理想气体处理，会高估熵贡献，从而得到不合理的自由能。

### 13.3 低频模式怎么处理

表面体系中低频模式常常会导致熵项不稳定。常见处理方式包括只考虑局部振动、固定远离反应中心的 slab 原子，或在论文中说明低频模式处理方法。关键是保持所有构型处理方式一致。

### 13.4 频率计算要和优化参数完全一样吗

核心参数应保持一致，例如泛函、赝势、`ENCUT`、`KPOINTS`、自旋和溶剂模型。频率计算可以提高 `EDIFF`，关闭对称性，并关闭不必要的波函数和电荷密度输出。
